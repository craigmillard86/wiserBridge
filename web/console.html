This browser can't talk to USB serial ports. Use Chrome or Edge on a desktop computer.

Not connected. Connect opens the browser's port list; pick the board (usually "USB JTAG/serial debug unit"). Connecting restarts the board once. It stays joined.

Join your Wiser network

  1. In the Wiser app, start adding a device so the hub opens pairing.
  2. Click Join, or press the BOOT button on the board once. After a minute, click Status.
    JOINED_LINKS_PRESENT, JOINED_COORDINATOR_REACHABLE or JOINED_MULTIHOP_VERIFIED means it worked, and a new smart plug appears in the app.

Troubleshooting and options

Status says JOINED_THEN_REMOVED. The hub removed it. Check the identity: it should say HEIMAN and SmartPlug-EF-3.0. If it says DIY-ESP32C6, reset it to the defaults, then join again.

Lock it to your network (optional). The board joins whichever Zigbee network has pairing open. If a neighbour might be pairing a device at the same time: click Scan, open pairing in the Wiser app, click Scan again, and enter the EPID of the network that changed to OPEN.

Everything stays in your browser. To report a problem, save the log and attach it to a GitHub issue.
