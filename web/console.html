This browser can't talk to USB serial ports. Use Chrome or Edge on a desktop computer.

Not connected. Connect opens the browser's port list; pick the board (usually "USB JTAG/serial debug unit"). Connecting restarts the board once. It stays joined.

Setup steps

  1. Check the identity. It should say HEIMAN and SmartPlug-EF-3.0.
  2. Click Scan. Then start adding a device in the Wiser app and click Scan again. The network that changed to OPEN is yours. Copy its EPID here:
  3. With pairing still open in the app, join. After a minute check the status. A verdict starting with JOINED_ means it worked.
  4. Later, check what it's doing:

Everything stays in your browser. To report a problem, save the log and attach it to a GitHub issue.
