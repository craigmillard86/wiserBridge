2. Install

Plug the board in with a USB data cable, then click Install and pick its port from the list. It usually shows as "USB JTAG/serial debug unit".

Use Chrome or Edge on a desktop computer. This page must be opened over https.

When it asks about erasing:

  • New board, or switching firmware: erase.
  • Updating a router that is already joined: don't erase. It keeps its network membership and saved settings.

If the port doesn't connect, close any other program using it (serial monitor, esptool, the console tab), or hold BOOT while plugging the board in.

3. Set up and join

Open the console and follow the steps there: check the identity, find your Wiser network, then join.
